## Лабораторная работа №3: Основы JavaScript (Core JS)

В ходе выполнения данной работы были изучены базовые концепции языка JavaScript.

### Структура проекта (папка lab3)
- **`src/core.js`** — основной файл с реализацией всех 10 учебных функций (заданий).
- **`src/core.spec.js`** — файл с тестами (Mocha), которые автоматически проверяют корректность написанного кода.
- **`package.json`** — конфигурационный файл проекта, содержащий зависимости (Mocha, Prettier) и команды для запуска.
- **`.gitignore`** — файл, указывающий Git, какие папки не нужно загружать в репозиторий (например, `node_modules`).
- **`.prettierrc`** — настройки для автоматического форматирования кода.

### Результат работы
Все задания выполнены и проходят проверку. При запуске команды `npm test` все 16 тестов успешно проходят (16 passing).
