## Лабораторная работа №2
**Тема:** многостраничный сайт про скалолазание.  
**Структура сайта:**  
- `index.html` — главная страница: что такое скалолазание, дисциплины, сравнение дисциплин (таблица), галерея изображений;
- `safety.html` — правила безопасности и снаряжение;
- `climbing.html` — скалодромы Самары.  
**Реализовано:**  
- 3 страницы, связанные навигационным меню;
- отдельный файл стилей `css/style.css`, подключённый ко всем страницам;
- таблица сравнения дисциплин с разными видами выравнивания: по левому краю, по центру и по правому краю;
- изображения скалодромов и дисциплин;
- использование блочных элементов (`<header>`, `<nav>`, `<section>`, `<div>`, `<table>`, `<ul>`, `<ol>`) и строчных (`<a>`, `<strong>`, `<em>`, `<img>`);
- CSS-селекторы: теговые, классовые, по идентификатору (`#main-title`), потомковые (`nav a`);
- цветовое оформление: шапка, меню, карточки, таблица;  
**Как посмотреть:**
Открыть файл `index.html` в браузере. Навигация между страницами — через меню сверху.

## Лабораторная работа №3: Основы JavaScript (Core JS)

В ходе выполнения данной работы были изучены базовые концепции языка JavaScript.

### Структура проекта (папка lab3)
- **`src/core.js`** — основной файл с реализацией всех 10 учебных функций (заданий).
- **`src/core.spec.js`** — файл с тестами (Mocha), которые автоматически проверяют корректность написанного кода.
- **`package.json`** — конфигурационный файл проекта, содержащий зависимости (Mocha, Prettier) и команды для запуска.
- **`.gitignore`** — файл, указывающий Git, какие папки не нужно загружать в репозиторий (например, `node_modules`).
- **`.prettierrc`** — настройки для автоматического форматирования кода.
